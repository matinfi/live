# Matin AI

افزونه `matin-ai-core` و قالب `matin-ai` برای پلتفرم گفت‌وگو با هوش مصنوعی و رزرو رویدادهای کافه‌ها.

- نیازمندی‌ها: WordPress 6.4+، PHP 8.0+ (آزمون‌شده با PHP 8.3)، افزونه‌های libsodium (در PHP پیش‌فرض است).
- نصب: پوشه‌های `matin-ai-core` را در `wp-content/plugins` و `matin-ai` را در `wp-content/themes` قرار دهید، افزونه را فعال و قالب را انتخاب کنید.
- دیتابیس: جداول `matin_ai_logs` و `matin_ai_messages` هنگام فعال‌سازی ساخته می‌شوند (نسخه ۳).

## تنظیمات لازم در پیشخوان

| بخش | تنظیم | یادداشت |
|---|---|---|
| هوش مصنوعی | ai_api_key | ذخیره به‌صورت رمزشده. همچنین ثابت یا متغیر محیطی `MATIN_GEMINI_API_KEY`، `MATIN_OPENAI_API_KEY` یا `MATIN_COMPATIBLE_API_KEY` (بسته به ارائه‌دهنده) قابل استفاده است. |
| واتساپ | whatsapp_phone_id و whatsapp_token | برای ارسال خودکار لازم است. بدون آن، پیام‌ها برای ارسال دستی آماده می‌شوند. |
| واتساپ | قالب‌های تأییدشده | پیام‌های آغازشده توسط کسب‌وکار در Meta باید قالب تأییدشده داشته باشند؛ در غیر این صورت ارسال خودکار رد می‌شود. |
| پیامک | sms_api_key و sms_sender | Kavenegar برای کد OTP. |
| Google | google_client_secret یا ثابت `MATIN_GOOGLE_CLIENT_SECRET` | آدرس بازگشت در Google Cloud: `{site}/my-account/?matin_oauth=google_callback`. |
| رزرو | require_phone_verification | در صورت فعال بودن، رزرو فقط برای کاربران با شماره تأییدشده ممکن است. |

## Cron

افزونه یک رویداد زمان‌بندی‌شده هر ۱۵ دقیقه (هوک `matin_ai_retry_messages`) برای تلاش مجدد پیام‌های ناموفق دارد. اگر WP-Cron غیرفعال است، یک cron واقعی سرور را روی `wp-cron.php` تنظیم کنید.

## رمزنگاری

کلیدهای API با libsodium و کلید مشتق‌شده از `wp_salt('auth')` رمزنگاری می‌شوند. اگر `AUTH_SALT` تغییر کند، کلیدهای ذخیره‌شده باید دوباره وارد شوند.

## آزمون

- واحد (بدون WordPress): `php tests/run.php`
- یکپارچه‌سازی: با WordPress روی SQLite و بررسی سناریوی رزرو، لغو، بلیت و دسترسی.

## محدودیت‌های شناخته‌شده

- اتصال زنده به WhatsApp، Kavenegar و Google در این نسخه روی سرویس واقعی آزمون نشده است.
- بلیت به‌صورت SVG تولید می‌شود (بدون QR)؛ به‌جای QR از کد اعتبارسنجی استفاده می‌شود.
- ورود با Apple حذف شده است.
- حذف داده‌های افزونه هنگام حذف (uninstall) پیاده‌سازی نشده است.
