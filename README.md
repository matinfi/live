# Matin AI

افزونه `matin-ai-core` و قالب `matin-ai` برای گفت‌وگو با هوش مصنوعی و کشف و رزرو رویدادهای کافه‌ها. نسخهٔ فعلی: **1.6.0**.

## نیازمندی‌ها

- WordPress 6.4+ و PHP 8.0+ (آزمون محلی روی WordPress 6.8 و PHP 8.3)
- libsodium برای رمزنگاری کلیدهای API (در PHP معمولاً فعال است؛ در نبود آن کلید بدون رمزنگاری ذخیره می‌شود)
- HTTPS برای نصب به‌عنوان اپلیکیشن (PWA)
- یک افزونه SMTP برای ارسال قابل اطمینان ایمیل‌ها (تأییدیه لغو، پیگیری مشتری، تأییدیه شکایت)

## نصب

1. پوشهٔ `matin-ai-core` را در `wp-content/plugins` و پوشهٔ `matin-ai` را در `wp-content/themes` قرار دهید.
2. افزونه را فعال و قالب `matin-ai` را انتخاب کنید.
3. هنگام فعال‌سازی، CPTهای کافه، رویداد، رزرو و شکایت ساخته و صفحات «درباره ما» و «شکایت و بازخورد» در صورت نبود ایجاد می‌شوند (بدون تکرار).
4. از «تنظیمات ← پیوندهای یکتا» یک بار ذخیره کنید تا مسیرها به‌روز شوند.

## قابلیت‌ها

- **گفت‌وگو با هوش مصنوعی** بر اساس کافه‌ها و رویدادهای ثبت‌شده؛ اگر رویدادی منطبق نباشد، صریحاً اعلام می‌کند.
- **رزرو و بلیت**: بلیت SVG قابل دانلود با کد `MAT-…`؛ لغو فقط تا ۶ ساعت قبل از شروع برنامه و به‌صورت اتمیک.
- **حساب کاربری** (`/my-account/`): ثبت‌نام، ورود، رزروها به تفکیک وضعیت، دانلود بلیت، لغو و تنظیمات نام و شماره.
- **پیشخوان**:
  - *مشتریان امروز*: ثبت حضور/غیرحضور و چاپ یا ذخیره به‌صورت PDF (از گفت‌وگوی چاپ مرورگر).
  - *ارسال پیگیری*: ایمیل با لینک اختصاصی شکایت برای هر مشتری.
  - *شکایت‌ها*: پیام‌های صفحه شکایت به‌صورت تیکت خصوصی با وضعیت و یادداشت.
- **PWA**: manifest، service worker و دکمهٔ «نصب اپلیکیشن».

## تنظیمات پیشخوان

| بخش | تنظیم | یادداشت |
|---|---|---|
| هوش مصنوعی | ارائه‌دهنده، نام مدل، کلید API | کلید رمزشده ذخیره می‌شود. ارائه‌دهندگان: OpenRouter، Gemini، OpenAI و سرویس سازگار با OpenAI. «تست اتصال» نتیجهٔ دقیق را نشان می‌دهد. |
| رزرو | قوانین لغو | قانون ۶ ساعت ثابت است و در سرور اعمال می‌شود. |
| بلیت | عنوان، یادداشت، پاورقی | متن بلیت و رسید لغو. |
| واتساپ | — | ارسال خودکار از طریق API رسمی پیاده‌سازی نشده است. متن پیام و لینک آماده می‌شود و ارسال دستی انجام می‌شود. |

## محدودیت‌های شناخته‌شده

- **تأیید شماره موبایل (OTP) پیاده‌سازی نشده است.** شماره فقط ذخیره می‌شود؛ برای OTP به یک سرویس پیامک نیاز است.
- **ارسال خودکار واتساپ** پیاده‌سازی نشده است؛ ارسال دستی انجام می‌شود و به‌عنوان ارسال موفق ثبت نمی‌شود.
- **PDF** از گفت‌وگوی چاپ مرورگر تولید می‌شود؛ PDF سمت سرور وجود ندارد.
- **یادآوری خودکار و ثبت حضور** حذف شده‌اند (cron استفاده نمی‌شود).
- **تلگرام** از بسته حذف شده است.
- رزروها طبق بسته‌ای که این نسخه از آن ساخته شده، پس از ثبت به‌صورت خودکار تأیید می‌شوند؛ تأیید دستی کافه در این نسخه فعال نیست.

## ساختار

- `matin-ai-core/includes/`: `class-matin-operations.php` (لغو، بلیت)، `class-matin-customers.php` (مشتریان امروز و پیگیری)، `class-matin-complaints.php` (شکایت‌ها)، `class-matin-pages.php`، `class-matin-pwa.php`، `class-matin-account.php`، `class-matin-admin.php`، `class-matin-rest.php`، `class-matin-ai-provider.php`، `class-matin-secrets.php`.
- `matin-ai/`: قالب کلاسیک RTL با `front-page.php`، `archive-*`، `single-*`، `assets/pwa.js` و `assets/pages.css`.

## آزمون

آزمون‌های انجام‌شده روی WordPress محلی با SQLite (نه MySQL)، شامل: فرم شکایت (ثبت، پیام کوتاه، honeypot، nonce نامعتبر، محدودیت نرخ)، صفحه حساب کاربری (قانون ۶ ساعت، لغو، دانلود بلیت)، تنظیمات حساب، ثبت‌نام، صفحات کافه و رویداد، آرشیوها، PWA، رمزنگاری کلید API و پیشخوان مشتریان. ارسال ایمیل در محیط آزمون در دسترس نبود و فقط مسیر خطای آن آزمون شد.
